# 書かずに済む道を探す

**足す前に、足さずに済むかを確かめる。** 書いたコードは、読む・直す・消す手間を持ち続ける。

このスキルは、[dietrichgebert/ponytail](https://github.com/dietrichgebert/ponytail)を、このプロジェクトに合わせて作り直したものである。

原典が入っていなくても動く。要るものは、このリポジトリの中にある。テンプレートは公開リポジトリで、ponytailを入れていない利用者がいるからである。**`Skill`の呼び出しに委譲しない。**

強さを切り替えるモードは持たない。モードを覚えておく仕組み（原典のhooks）が無いので、置いても次のセッションに残らない。

## いつ使うか

| 場面 | 合図 |
| --- | --- |
| 実装に着手する前 | 新しいモジュール・クラス・依存を足そうとしている |
| 差分を出す前 | 差分に新しいファイルが増えた。コミットやPRの直前 |

`/grill`の後に回す。何を作るかが決まっていないと、梯子の1段目（そもそも要るか）に答えられない。要件が曖昧なら、先に`/grill`を回す。

## 着手する前に、梯子を登る

### 1. 原則を読む

毎回、`docs/00-meta/principles.md`（META-06）を読む。梯子・削らないもの・過剰な実装の兆候は、そちらにしか書いていない。

### 2. 問題を理解する

登る前に読む。課題と、それが触るコードを読み、実際の流れを端から端まで追う。規定しているノードの近傍と、その`implemented_by`の指し先を読む。

```bash
python -m tools.graph render --format json --focus <ID> --depth 1
```

### 3. 上から順に当てる

1段目から当てはめ、最初に止まった段で終える。

2段目（すでにあるか）は、探してから答える。「たぶん無い」と考えて新しく書くと、似たものが2つになる。

```bash
git grep -n "<それらしい名前>"
```

3〜5段目は、入っているものを確かめてから答える。依存の一覧（`requirements.txt`、`package.json`など）を読む。標準ライブラリの機能は、実際に回している版にあるかを確かめる。

### 4. 止まった段を示してから書く

書き始める前に、どの段で止まったかを1行で示す。

```
梯子: 3段目で止まった。標準ライブラリのzoneinfoで足りる。依存は足さない。
```

**7段目まで来たときだけ、新しいコードを書く。** そのときも、動く最小のものにする。

依頼の一部が要らないと思ったら、書く前に聞く。何も言わずに削らない。依頼された機能を落とすのは簡略化ではなく、仕様の変更である。

## 差分を出す前に、読み返して削る

```bash
git diff
```

META-06の「過剰な実装の兆候」の表を、差分に上から当てる。当たったものは削る。残すなら、梯子の1段目に戻って、要る理由を言えること。

次に、「削らないもの」の表を当てて、削りすぎていないかを確かめる。入力検証やエラー処理は、差分が長くなっても残す。

簡略化した箇所には、限界と、引き上げる条件を書く。書き方は、META-06の「書かなかったものを残す」にある。

## 報告の形

コードを先に出し、説明は短くする。省いたものは1行で書く。

```
省いたもの: キャッシュ。同じ値を2度読む箇所が無い。遅くなったら足す。
```

会話に書いただけでは、次のセッションに残らない。「足す条件」は、コードのコメントかADRにも残す。

## やってはいけないこと

| やってはいけないこと | 理由 |
| --- | --- |
| 理解する前に登る | 最短の差分が、間違った場所の差分になる |
| 削らないものを削る | 梯子は何を書かないかを決める道具で、守りを外す道具ではない |
| 依頼を、何も言わずに削る | 要らないと思うなら、書く前に聞く |
| 2段目を推測で済ませる | 探してから答える |
| 読めない1行を書く | 6段目は、読める1行のことである。賢い1行より、退屈な数行のほうが良い |

## 終わる条件

- [ ] 止まった段を示した
- [ ] 差分に「過剰な実装の兆候」が残っていない（残したなら、要る理由を言える）
- [ ] 「削らないもの」を削っていない
- [ ] 簡略化した箇所に、限界と引き上げる条件が書いてある
- [ ] 自明でないロジックに、動くことを確かめる検査が1つある
- [ ] 文書を触ったなら、`check`が通る
