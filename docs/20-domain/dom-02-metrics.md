# エンゲージメント指標と注目度

## 定義

**エンゲージメント指標**は、1 つの投稿に対する反応の数。6 種類あり、
すべて同じ取得で一度に返ってくる。

**注目度**は、そのうち **保存数**（あとで見返すために保存した人数）で表す。
「見られた回数」ではなく「取っておこうと思われた回数」を注目度とする（[ADR-0002](../50-adr/adr-0002-save-count-as-metric.md)）。

## 属性

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| 保存数 | 整数 | ○ | **注目度の代表値。** 判定に使うのはこれだけ |
| 表示数 | 整数 | | 何回表示されたか。記録するが判定には使わない |
| 転載数 | 整数 | | 何人が転載したか |
| 引用数 | 整数 | | 何人がコメント付きで転載したか |
| 好意数 | 整数 | | 何人が好意的な反応を示したか |
| 返信数 | 整数 | | 何件の返信が付いたか |

**6 種類すべてを記録する。** 同じ取得結果に含まれており、記録しても費用は増えない。
判定に使う指標を後から変えられる余地を残すためでもある。

## 不変条件

- [ ] 6 種類はすべて 0 以上の整数である
- [ ] 値が取得できなかったこと（項目が無い）と、値が 0 であることは**区別する**。
      前者は異常の可能性があり、後者は正常な状態
- [ ] **同じ投稿の保存数は時間とともに減らない。** 減っていたら取得の異常を疑う
- [ ] 転載された投稿の指標はすべて 0 になる。これは仕様であり異常ではない

## ライフサイクル

投稿された直後から増え始め、日を追って伸びが緩やかになる。
実測では**投稿当日から 2 日後にかけて中央値が約 2 倍**になり、
それ以降は測定できていない（[ADR-0003](../50-adr/adr-0003-tracking-window.md)）。

## 用語

| 用語 | 意味 | 使ってはいけない言い換え |
| --- | --- | --- |
| 保存数 | あとで見返すために保存した人数。注目度の代表値 | ブックマーク数（媒体の名称。媒体が変わると文書ごと古くなる） |
| 表示数 | 何回表示されたか | インプレッション（判定に使わない指標なので、目立つ名前を与えない） |
| 注目度 | 保存数で表した、その商品への関心の大きさ | 人気度、話題性（好意数や返信数と混同される。注目度は保存数のこと） |
| 閾値 | それを超えたら通知する保存数の値 | 基準値（何の基準かがぼやける） |
