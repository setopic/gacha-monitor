# 監視対象と投稿

## 定義

**監視対象**は、商品の告知を継続的に発信している 1 つの公開アカウント。
**投稿**はその監視対象が発信した 1 件の文であり、そのうち
**監視対象自身が書いたもの**だけを追跡の対象とする。

## 属性

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| 投稿 ID | 文字列 | ○ | 投稿を一意に指す。追跡と通知済みの判定はこれで行う |
| 投稿日時 | 日時 | ○ | 追跡期間の起点 |
| 本文 | 文字列 | ○ | 商品名を含むことが多いが、形式は保証されない |
| 種別 | 列挙 | ○ | 自作 / 転載 / 引用 / 返信 |
| 経過日数 | 整数 | ○ | 投稿日時から測った日数。追跡を打ち切る判定に使う |

## 不変条件

- [ ] 投稿 ID は監視対象をまたいで一意である
- [ ] **種別が自作でない投稿は追跡しない。** 転載は反応の数が構造上すべて 0 を返し、
      引用と返信は商品の告知ではない（[[ADR-0005]]）
- [ ] 追跡するのは、投稿日時からの経過日数が追跡期間の内側にある投稿だけ
- [ ] 投稿の本文に商品名が含まれる保証はない。含まれないことを異常として扱わない

## ライフサイクル

```
投稿される → 追跡期間の内側にある間、毎日 1 回測られる → 期間を過ぎたら測らなくなる
```

**削除された投稿は取得結果から消える。** 消えたことは異常として扱わず、
その投稿の追跡が終わったものとして扱う。

## 用語

| 用語 | 意味 | 使ってはいけない言い換え |
| --- | --- | --- |
| 監視対象 | 追跡している 1 つの公開アカウント | 監視先、ターゲット（人を追う語感になる。追っているのは商品告知） |
| 投稿 | 監視対象が発信した 1 件の文 | ツイート（媒体の名称に寄ると、媒体が変わったとき文書ごと古くなる） |
| 自作 | 監視対象自身が書いた投稿 | オリジナル（英語のままだと転載との対比が伝わりにくい） |
| 転載 | 他者の投稿をそのまま流したもの | リポスト、リツイート（媒体の名称） |
| 追跡期間 | 1 つの投稿を測り続ける日数 | 収集期間、監視期間（何を数える期間かがぼやける） |
