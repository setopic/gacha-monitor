# ドメイン（層 20）

概念・属性・不変条件・用語。**この層の言葉が、上の層すべての共通語彙になる。**

書かないこと: 画面、エンドポイント、フレームワークの都合。
ユースケースを参照したくなったら、それは概念の切り出しが足りていない合図。

## 用語の一覧（自動生成 / 手で編集しない）

各ドメインノードの「用語」表を集めたもの。**直すときは元のノードの表を直す。**
同じ意味のことを書くときは、ここにある語を使う。

### [DOM-01 監視対象と投稿](./dom-01-post.md)

| 用語 | 意味 | 使ってはいけない言い換え |
| --- | --- | --- |
| 監視対象 | 追跡している 1 つの公開アカウント | 監視先、ターゲット（人を追う語感になる。追っているのは商品告知） |
| 投稿 | 監視対象が発信した 1 件の文 | ツイート（媒体の名称に寄ると、媒体が変わったとき文書ごと古くなる） |
| 自作 | 監視対象自身が書いた投稿 | オリジナル（英語のままだと転載との対比が伝わりにくい） |
| 転載 | 他者の投稿をそのまま流したもの | リポスト、リツイート（媒体の名称） |
| 追跡期間 | 1 つの投稿を測り続ける日数 | 収集期間、監視期間（何を数える期間かがぼやける） |

### [DOM-02 エンゲージメント指標と注目度](./dom-02-metrics.md)

| 用語 | 意味 | 使ってはいけない言い換え |
| --- | --- | --- |
| 保存数 | あとで見返すために保存した人数。注目度の代表値 | ブックマーク数（媒体の名称。媒体が変わると文書ごと古くなる） |
| 表示数 | 何回表示されたか | インプレッション（判定に使わない指標なので、目立つ名前を与えない） |
| 注目度 | 保存数で表した、その商品への関心の大きさ | 人気度、話題性（好意数や返信数と混同される。注目度は保存数のこと） |
| 閾値 | それを超えたら通知する保存数の値。**3 段階あり、上の段階に届くたびに 1 回ずつ通知する**（[ADR-0008](../50-adr/adr-0008-raise-thresholds.md)） | 基準値（何の基準かがぼやける） |
