# 閾値を 1,000 / 2,000 / 4,000 に引き上げる

- 日付: 2026-09-15
- 状態: stable

## 背景

[ADR-0004](./adr-0004-three-thresholds.md) は 500 / 1,000 / 2,000 を選んだ時点で、
通知量が 8.6 件/日になることを承知していた。「1 日に数件なら許容できる」という
判断に対してやや多いが、**閾値は設定シートで即座に変えられるので、
運用の体感を見てから絞るほうが確実**という理由でこの刻みを採った。

1 週間の運用で体感が出た。**500 の段には、注意すべき水準に達していない商品が
ままあった。** ADR-0004 の見直しの条件のうち
「通知が多すぎて読まれなくなったとき（閾値を上げる）」に該当する。

## 決定

**閾値を 3 段階（1,000 / 2,000 / 4,000）に引き上げる。**

[ADR-0004](./adr-0004-three-thresholds.md) の決定のうち、**値だけを改め、構造はすべて引き継ぐ。**

1. 3 段階置く — **そのまま**
2. 上の段階に届くたびに 1 回ずつ通知する（1 投稿につき最大 3 回） — **そのまま**
3. 同じ段階では二度通知しない — **そのまま**
4. 2 段階目に `【要チェック】`、3 段階目に `【要注意！！】` を付ける — **そのまま**
5. 初回にはラベルを付けない — **そのまま**
6. 値を 500 / 1,000 / 2,000 とする — **改める。1,000 / 2,000 / 4,000 にする**

## 理由

**通知量がおよそ半分になる。** 1 週間ぶんの実測から、段階ごとの発生頻度は次のとおり。

| 段階 | 該当した投稿 | 1 日あたり |
| --- | --- | --- |
| 1,000 | 23 件 | 2.9 件 |
| 2,000 | 15 件 | 1.9 件 |
| 4,000 | 2 件 | 0.3 件 |
| **合計** | — | **約 5.1 件** |

現行の刻みでは、ここに 500 の段（最も件数の多い層）が加わる。
ADR-0004 の時点の実測では 500 の段だけで 5.2 件/日 を占めていた。
**引き上げの効果は、ほぼこの層を落とすことに尽きる。**

**刻みを 2 倍ずつにしたのは、段階の間隔を保つため。**
ADR-0004 は 500 / 2,000 / 5,000 を「初回と 2 段階目の間が空きすぎる」として
却下している。1,000 / 2,000 / 4,000 は各段が 2 倍で、その性質を保っている。

**4,000 は「その週の最大級」を指す水準になる。** 1 週間で 2 件しか届かず、
実測の最大は 6,332。上限に張り付かず、かといって毎日は鳴らない位置にある。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 700 / 2,000 / 5,000 | 初回の段が 3.8 件/日 と中途半端に残る。**500 が多すぎるという体感に対して、効きが弱い** |
| 1,000 / 3,000 / 7,000 | 2 段階目以降がほとんど鳴らない（3,000 で 0.4 件/日）。段階を 3 つ置く意味が薄れる |
| 1,000 の 1 段階のみ | 2.9 件/日 で最も静か。ただし ADR-0004 と同じ理由で、大きく化けた商品が埋もれる |
| 実測から逆算した値（週 2 件） | ADR-0004 で既に却下している。取りこぼしが多すぎる |

## 影響

- [UC-01](../30-usecases/uc-01-detect-and-notify.md): 判定の値が変わる。通知済み段階の管理の仕組みは変わらない

**設定シートの「閾値 1〜3」を書き換えるだけで反映される。** コードは変わらない。

**[ADR-0007](./adr-0007-tracking-window-2days.md) と同じ日に決めている。** 追跡期間の短縮と閾値の引き上げは
どちらも通知を絞る方向に働き、効果が重なる。境目に近い投稿
（1 日後に 993、2 日後に 1,002 のような）は両方の影響を受けて落ちるが、
**これは狙って落としている層である。**

## 見直しの条件

- 通知が少なすぎて、発売後に初めて気づく商品が出たとき（閾値を下げる）
- 週次サマリーの最大保存数が 1,000 に遠く届かない週が続くとき（閾値を下げる）
- 監視対象を変えたとき。**閾値は監視対象の規模に依存する。** 別のアカウントに
  同じ値をそのまま当てても意味を持たない
- 監視対象の規模が大きく変わったとき。フォロワーが増えれば保存数の水準も上がる
